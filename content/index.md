# Minicurso de Realidade Aumentada na Web (WebAR)

Bem-vindo(a) ao **Minicurso de Realidade Aumentada na Web (WebAR)**! Este portal foi desenvolvido para guiar você, passo a passo, no desenvolvimento de experiências interativas e imersivas em 3D utilizando apenas tecnologias web abertas.

Aqui você aprenderá a construir portfólios de realidade aumentada de alto impacto que rodam direto no navegador do celular — sem precisar de downloads de lojas de aplicativos, usando apenas HTML, JavaScript e as bibliotecas **[A-Frame](https://aframe.io/)** e **[AR.js](https://ar-js-org.github.io/AR.js-Docs/)**.

---

## 🎯 O que você vai aprender?

O curso está estruturado em uma sequência lógica projetada tanto para iniciantes quanto para desenvolvedores que desejam expandir seus conhecimentos:

1. **Configuração & Ferramentas:** Do versionamento com Git/GitHub até o setup do ambiente de trabalho.
2. **Fundamentos 3D & HTML:** Compreendendo a estrutura do HTML aplicada a tags tridimensionais com A-Frame.
3. **Realidade Aumentada por Marcadores:** O ecossistema do AR.js, câmera virtual e o clássico marcador Hiro.
4. **Customização & Criação:** Como projetar seus próprios marcadores visuais.
5. **Estilização e Recursos Visuais:** Projeção de imagens 2D, tratamento de canal alfa e criação de efeitos "outdoor".
6. **Movimento & Interação:** Animações nativas, encadeamento de animações e interação dinâmica via JavaScript.
7. **Deploy:** Publicação gratuita do seu projeto na web.

## 🚀 Como navegar no curso?

Você pode acompanhar as aulas de duas formas:

- **Menu Lateral:** Use a barra de navegação à esquerda para pular diretamente para qualquer capítulo que queira estudar ou revisar.
- **Fluxo Contínuo:** No final de cada página de capítulo, você encontrará botões inteligentes para avançar para a próxima aula ou retornar para a anterior.
